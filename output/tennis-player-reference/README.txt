TENNIS PLAYER — REFERENCE STUDY

Editable Blender file: tennis-player-reference.blend
Frame 1: neutral reference stance.
Frame 40: ready grip study (arm pose only; not a finished stroke animation).
The render script adds the racket for the ready preview.

The two reference PNGs were supplied by the user. This model approximates the
references; it is not a photogrammetric reconstruction or an exact likeness.

Generation:
D:\blender\blender.exe --background --python scripts\create-tennis-player-reference.py
Run from D:\dev\stevenchendan.github.io.
The script shares modeling helpers with scripts/create-tennis-player-v2.py.

Base anatomy: MakeHuman base.obj, CC0, from the existing .astro source assets.
Male/athletic morphs: MakeHuman Community MPFB macrodetails, CC0.
Skin texture: existing project .astro/skin-diffuse.jpg.
See public/models/tennis/motion-credits.txt for the project's source credits.
Clothing, hair curves, headband, footwear, racket, pose weights, and studio
scene were authored for this study using Blender Python.

This study does not change the website or its deployed player assets.
